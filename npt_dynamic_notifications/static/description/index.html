Dynamic Notifications

Create configurable event-based notification rules for Odoo records and route them through each user's preferred delivery channels. Rules can react to record creation, updates, selected field changes and custom events, helping teams automate operational alerts without building a separate notification flow for every business case.

The addon supports Odoo email and inbox delivery and can also send WhatsApp messages when the optional odoo_whatsapp_meta companion module is installed and configured.

Key Features

Event-Based Rules

Trigger notification rules on record creation, write operations, selected field/state changes, or custom events.

Any Configured Odoo Model

Select the model for each rule and optionally apply a rule to inherited models where supported.

Conditional Domains

Use an optional Odoo domain to restrict notifications to records matching business conditions.

Flexible Recipient Selection

Send to fixed internal partners, the record's user, a partner/user field on the record, or users belonging to selected security groups.

User Channel Preferences

Users can choose supported dynamic notification channels from their notification preferences.

Stock Operation Type Filter

For records exposing an operation type, rules can be restricted to selected stock operation types.

Template-Based Messages

Define subject and HTML message templates using record, current user and event context.

JSON Import / Export

Export selected notification rules and import rule settings into another database, with options to replace or update matching rules.

Build Rules Around Business Events

Administrators configure the target model, trigger, optional field/domain filters, recipients, stock operation types and message templates. When the configured event occurs and the record matches the rule, the addon prepares and dispatches the notification.

Route Through Supported Channels

Dynamic notification preferences are available on Odoo users. Email and inbox delivery use Odoo's mail framework. WhatsApp delivery is enabled only when the optional odoo_whatsapp_meta module is installed and its WhatsApp service is available.

How It Works

  1. Open Dynamic Notifications as an administrator.
  2. Create a rule and choose the target Odoo model.
  3. Select Create, Write, State Change or Custom as the event type.
  4. Optionally configure a field gate, domain, inherited-model behavior or stock operation types.
  5. Choose the recipient strategy and configure the subject/message templates.
  6. Set supported delivery channels on users according to your notification policy.
  7. When the event matches, the addon posts the notification and optionally routes WhatsApp where available.

Typical Use Cases

  • Notify responsible users when a business record is created.
  • Alert teams when a selected status/state field changes.
  • Send conditional alerts only when records match an Odoo domain.
  • Notify members of selected user groups.
  • Route notifications to a partner/user field stored on the record.
  • Limit inventory-related notifications by operation type.
  • Move notification rule settings between Odoo databases using JSON.
  • Extend a custom workflow by calling the included custom-event helper.

Requirements

  • Odoo 18.0
  • Standard dependencies: Base, Mail, Stock and Web
  • WhatsApp is optional and requires the separate odoo_whatsapp_meta module

Technical Information

  • Technical module: npt_dynamic_notifications
  • Administrator configuration menu
  • JSON settings import/export support
